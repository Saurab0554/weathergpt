Quick safety guide

Three useful rules for handling sensitive files.

Use a secure, updated device and browser.
Prefer official portals; type the address yourself.
Delete extra copies from downloads and shared folders.
Use a redaction tool that removes underlying content.

These tools offer convenience, not a security guarantee. Image flattening can remove common metadata; it does not hide visible information or prove a file is safe.

03 / Safer browsing

Pause before
you tap.

Inspect a URL for common warning signs before visiting. SAFESCANX never opens the address or sends it to a reputation service.

Local link inspection

Paste a URL to check its structure. This cannot confirm a site is safe or detect malware.

Your check runs in this browser. No network lookup is performed.

Before you open a link

Use these checks even when a URL looks familiar.

Check the exact spelling of the domain.
Be wary of urgent requests for passwords or payment.
Do not trust a padlock alone; HTTPS does not prove legitimacy.
Open government and bank sites from a known official source.
Never install files or extensions prompted by an unknown page.

What the local check looks for

Lookalike patterns — long or unusually encoded addresses.
Unexpected domains — IP addresses, odd ports, or punycode.
Risky redirects — URL shorteners and embedded destinations.

What this check cannot tell you

Whether a site is currently compromised or malicious.
Whether a downloaded file contains malware.
Whether a legitimate-looking page is impersonating an organization.
A “no obvious warning” result is not a safety certification. For higher assurance, use a trusted security product and navigate to sensitive services through their official app or a bookmarked address.

05 / Trust, by design

Privacy should be
the default.

SAFESCANX follows a simple principle: sensitive documents should be inspected on your device, and only shared when you choose.

SAFESCANX’s demo protocol

1. Select locally — your browser reads the chosen file through a local file handle.
2. Inspect locally — the demo uses lightweight browser-side heuristics and image previews.
3. Share intentionally — you decide what to download and where to send it.
4. Clear the session — reload or close the tab to discard in-memory previews.

What this prototype does not do

It does not provide certified OCR, malware scanning, or identity protection.
It does not automatically upload to a government or other portal.
It does not guarantee complete metadata removal or secure redaction.
Your browser extensions and device environment remain outside this page’s control.

Private-by-design checklist

No account or user profile is required.
No document server upload is part of this prototype.
No link reputation request is sent.
No background storage is used for selected files.

For a production launch

Publish the privacy protocol alongside the product and verify it technically.

Host with a strict content security policy and minimal third-party scripts.
Use audited local OCR and verified deletion workflows.
Document limits, threat model, and data flow clearly.
Provide independent security review and accessible alternatives.

This hackathon prototype is a static browser demo, not a certified document-security product. External font styling may contact Google Fonts; document files themselves are never sent by this page.
